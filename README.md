# Java Engineering Field Guide

A free, hands-on guide that takes you from data structures to AI agents in Java.

**Read it here:** https://kssasarma.github.io/java-engineering-field-guide/

## What's inside

140 concepts in 7 tracks, in learning order:

| Track | Topics |
|---|---|
| 1. Data Structures & Algorithms | Arrays and hashing through graphs, Dijkstra, greedy and dynamic programming |
| 2. Low-Level Design | OOP, UML, SOLID, 13 design patterns, thread safety, machine coding |
| 3. Backend Engineering | HTTP, REST, databases, transactions, auth, Redis, queues, WebSockets, testing |
| 4. Cyber Security | OWASP Top 10, TLS, JWT, OAuth, XSS, CSRF, SSRF, prompt injection |
| 5. DevOps | Linux, Docker, CI/CD, AWS, Terraform, Kubernetes, Helm, observability |
| 6. High-Level Design | Scalability, sharding, CAP, Kafka, microservices, sagas |
| 7. AI Agentic Engineering | LLMs, RAG, tool calling, MCP, agents, guardrails, evals, LoRA |

Every concept has:

- an analogy and the core idea
- why it's needed and real use cases
- when to use it and when not to
- side effects of using it and of not using it
- configuration (Spring Boot 4, Spring AI 2.0 and more)
- Java code, including a runnable demo with its expected output
- a hands-on lab and an interview question

## Running the demos

Each runnable demo starts with `// File: Name.java`. Copy it with the **Copy** button, save it as `Name.java`, and run:

```bash
java Name.java        # JDK 21 or newer, no build tool needed
```

## Using the page

- Search with the box at the top (press `/` to jump to it).
- Mark concepts as done to track progress. Progress is saved in your browser only.
- Light and dark themes follow your system setting.

The whole guide is one self-contained `index.html`, so you can also download it and open it offline.
